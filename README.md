Добро пожаловать в инструкцию по работе с клиент-серверным приложением чата!
Для начала работы необходимо запустить сервер. После запуска сервера должно появиться окно терминала, сообщающее, что сервер запущен и на каком порту он запущен. Если терминал закрыть, то сервер перестанет работать. 
![image](https://github.com/user-attachments/assets/8cf76039-bff3-48ac-a0bd-0bc9398b878e)

Если это первый запуск сервера, и база данных приложения пуста, то создаться первый пользователь чата с правами админа и ником admin, в терминал, в таком случае выведется запись «Создан пользователь-администратор с именем 'admin'».
После запуска сервера, можно запускать клиентскую часть приложения. 
Клиентскую часть приложения можно запускать несколько раз, для имитации работы нескольких пользователей.
![image](https://github.com/user-attachments/assets/163da6ec-60dd-454a-98c7-8f969e1cae0d)

Клиентское приложение начинается с экрана регистрации/логина. По умолчанию должен создаваться пользователь admin. 
В приложение можно войти по уже существующему нику, или зарегистрироваться под новым. Новые пользователи создаются без прав админа.
 ![image](https://github.com/user-attachments/assets/81f27051-f8ac-42a8-98ed-ed28eea8cf34)

При попытке войти под незарегистрированным в базе логином, или под логином, под которым уже есть вошедший пользователь, программа это не разрешит. При попытке регистрации уже существующего логина так же появится уведомление. 
 ![image](https://github.com/user-attachments/assets/456100f0-3f20-42bd-9303-3de7c8c54deb)

При входе появляется основное окно приложения. В левой части расположенны контакты, при щелчке по строке открывается беседа с этим контактом. Зеленые кружочки рядом с именем обозначают что данный человек в сети, красный, что его сейчас в подключении нет. Синий кружочек рядом с именем обозначает, что от этого контакта есть непрочитанные сообщения.   
 ![image](https://github.com/user-attachments/assets/84add08e-bf2c-4a0e-96ab-578fbe71dbbc)

 ![image](https://github.com/user-attachments/assets/3b26a31a-a212-4c01-854a-8659e9ce5c77)

При нажатии кнопки «добавить пользователя» появится окошко добавления. У пользователя без прав админа появится сообщение, что у него недостаточно прав на это действие. В окне добавление пользователя можно ввести имя нового пользователя, и, при желании, дать ему права админа.
![image](https://github.com/user-attachments/assets/a23f7093-042e-49f6-8d1a-0ee71568a293)

![image](https://github.com/user-attachments/assets/bb81a525-c17c-4a6c-a299-dfe3f1b3a105)

Для удаления пользователя, необходимо выделить его в списках контактов и нажать кнопку «удалить пользователя», после чего появляется подтверждающий диалог. Удалять пользователей имеют право только админы.
 ![image](https://github.com/user-attachments/assets/a3d647de-bb7e-4807-be85-cbfd06b23725)

 ![image](https://github.com/user-attachments/assets/348df8bf-11ff-4c28-964e-9ee76fd151a0)

 ![image](https://github.com/user-attachments/assets/d9ad6582-be50-4268-8e2b-d88983d453ca)

 ![image](https://github.com/user-attachments/assets/a47564bf-3811-4558-a7c7-43184dfe1b66)

Кнопки с плюсами, рядом с именами пользователей, означает, что вы можете добавить «подписку» на этого пользователя, это значит, что вы будете получать уведомления, когда этот пользователь заходит или выходит из программы.
 ![image](https://github.com/user-attachments/assets/08a212f5-eeb5-4910-9c2d-45c65287e2ec)

При добавлении значок на кнопке меняется на минус. Так можно различить, на каких пользователей вы подписаны.
 ![image](https://github.com/user-attachments/assets/7c00447d-20df-4a19-95b8-10694c8d5b74)

 ![image](https://github.com/user-attachments/assets/884f7b16-d5a1-4a95-985d-c13310c05603)

Повторное нажатие на кнопку отменяет подписку.
 ![image](https://github.com/user-attachments/assets/e8b36240-e6ce-4ea0-9417-a79a086a9bc1)

Все действия по входу-выходу пользователей, регистрации и удалении логируются в терминал сервера. 
 ![image](https://github.com/user-attachments/assets/6e4c5f94-abb3-4133-ade2-16cbf8e61c4a)
